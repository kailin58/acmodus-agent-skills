## 八、3D试穿主线(产品核心场景,2026-09-21定稿)
**用户愿景原话**:"有了人体/有了白底图/2.5D/3D/在不同的场景/用户就可以穿上3D服装可以行走/展示/等"

### 核心用户旅程
1. 用户上传照片 → 抠图 → 白底图 → 2.5D深度 → 3D人体(尺寸可调:测量头→体型参数→Anny形变)
2. 用户上传商品图(服装/饰品/鞋/配饰/化妆品等) → 抠图 → 白底 → 2.5D → 3D商品mesh(图像驱动,每件唯一,禁模板)
3. 衣服挂载到人体(13718恒定顶点=挂载点) → **用户穿上3D服装**
4. 不同场景(街拍/影棚/舞台等) + **行走/动态展示**(104骨骼驱动)
5. (可选)换脸=虚拟的自己;拍照测量=按用户真实尺寸调人体

### 功能清单(3D试穿模块)
- F1 商品3D化:任意商品照片→唯一3D资产(全品类:服装/饰品/鞋/包/化妆品)
- F2 人体3D化:照片→体型匹配的可动3D人体
- F3 试穿合成:衣服挂载人体,贴合不穿模
- F4 场景引擎:多场景切换(光照/地面/背景)
- F5 动态展示:行走/转身/姿势(骨骼动画)
- F6 虚拟自己:换脸接入+尺寸定制
- F7 全链端侧(≤350MB VTON预算内,隐私零上传)

### 验收
- 不同商品图→不同mesh(唯一性哈希校验)
- 穿上后行走动画不穿模、衣服跟随体态
- 场景切换实时
- 端侧实时渲染(iPhone13/2020安卓)

## 九、技术雷达(用户关注,择机接入)
- RLCD(Reinforcement Learning for Calibrated Decisions,校准决策强化学习):模型置信度必须诚实(说80%长期对80%)。定位=训练方法(不是部署后处理):在测量头v2/风格识别器v2的训练目标里加校准奖励项(MSE/CE+校准),从骨子里学会诚实置信度;推理期零成本。价值:端侧小模型在差光照/遮挡/半身输入上报可信区间(身高170±3cm/置信72%),App据此决定收下或让用户重拍。时机:两模块进App联调后。来源:用户2026-09-21提(B站视频"RLCD:第三条路")
