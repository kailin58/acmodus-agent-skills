# 端侧总体积红线 v2.1(六模块全装版)

> 2026-09-17 依据用户指令:考虑用户手机装多个应用、用户数据也占硬盘,必须定总体积红线
> 上承:端侧模型体积能力平衡规格.md v2.0(单模块版) · 本文档=全App视角

## 一、总红线(硬约束,超了就砍)

| 项 | 红线 | 目标 |
|---|---|---|
| **App安装后总占用**(含全部6模块模型) | **≤1GB** | **≤600MB** |
| 首次下载安装包(应用商店) | ≤400MB,其余模型首次启动按需下 | ≤250MB |
| 运行内存峰值(换装进行时) | ≤3GB | ≤2GB |
| **用户数据+缓存** | ≤1.5GB 自动封顶 | ≤800MB |

依据:iPhone 13 基础128GB、2020安卓128GB,用户普遍装50-100个应用,单App超2GB会被用户优先卸载;1GB是"重型应用"可接受上限,600MB是"礼貌占用"。

## 二、六模块模型预算分配(合计≤600MB目标)

| 模块 | 预算 | 方案 |
|---|---|---|
| 换装VTON(主模型) | ≤350MB | 415M学生模型 INT8(规格v2.0不变) |
| 换脸 | ≤80MB | 轻量swap模型蒸馏+INT8 |
| 化妆/补妆/补光 | ≤30MB | MediaPipe FaceMesh+小回归头 |
| 抠图 | ≤10MB | u2netp级(INT8) |
| 拍照测量 | ≤15MB | Pose lite(~5MB)+Anny回归头(~5MB) |
| 穿搭推荐 | ≤15MB | 知识库JSON(600KB)+轻量排序头 |
| 真3D(人体基底) | ≤80MB | Anny mesh+blendshape;**衣服mesh不打包,按衣柜单品流式加载** |
| 预留/量化开销 | ≤20MB | — |
| **合计** | **≤600MB** | |

## 三、用户数据策略(硬盘占用)

1. **衣柜3D资产不进安装包**:按用户添加的单品按需下载,单件≤10MB(1k面mesh+2K贴图压缩)
2. **生成图缓存LRU封顶500MB**,自动清最旧;WebP/HEIC压缩存储
3. 试穿历史/偏好画像:纯结构化数据,<50MB
4. 设置页必须给「一键清空缓存」「数据导出/删除」(隐私铁律要求)
5. 模型更新走差分包(OTA只下变化层)

## 四、验证方式
每轮蒸馏/量化后:真机装App实测 安装占用/内存峰值/硬盘增长曲线,三档真机(小米/OPPO/荣耀+iPhone13)全达标才过——沿用规格v2.0验收纪律。
