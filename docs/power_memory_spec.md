# 端侧功耗与内存优化规格 v1(目标:10倍优于未优化基线)

## 精度门槛(并行铁律)
| 模型 | 同行参照 | 我们目标 |
|---|---|---|
| 品种识别 | 通用API~90% | ≥93%(蒸馏不丢>3pt) |
| 人体测量 | 拍照测量类±3-5cm | ±0.15cm |
| 妆容/试穿 | 生成类无标尺 | 视觉验收≥8.5 |

## 功耗优化(10倍路径)
1. **量化双档**:INT8权重+FP16激活(计算量×0.5,带宽×0.25)
2. **NPU委托**:CoreML(iOS)/NNAPI(安卓)→GPU卸载CPU,NPU能效比CPU高10-30倍
3. **算子融合**:Conv+BN+ReLU融合(离线烤进ONNX,推理次数-40%)
4. **动态分辨率**:输入按设备档降采样(T2:112px替代224px,功耗×0.25)
5. **推理缓存**:同一图7模块串联时,backbone只跑1次(共享特征,功耗×1/3)
6. **懒加载+休眠**:模块不用不加载,10分钟闲置卸载

## 内存优化
1. 峰值预算:总≤3GB,单模块≤400MB
2. mmap权重(不整载入)
3. 零拷贝图传递(模块间共享bitmap)
4. 中间tensor复用池

## 验收(真机)
iPhone13/2022安卓实测:单模块推理能耗(J/次)/延迟(ms)/峰值内存(MB)
横向对比未优化版=必须≥10倍能效提升
