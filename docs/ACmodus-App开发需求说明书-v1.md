【ACmodus 端侧AI形象系统 — App端开发需求说明书 v1.0】

■ 项目一句话
ACmodus:手机离线AI形象系统。模型侧(已完成93%)输出轻量端侧模型(≤500MB/内存≤3GB/63ms推理),App侧负责壳+体验+渲染,三者(模型×环境×App)通过标准数据合同融合。目标机型:iPhone13+/2020年安卓旗舰;支持手机/平板/PC。

■ 一、总体分工(铁律)
你管"壳+体验+渲染",模型侧管"脑+内容"。
- 模型侧提供:全部AI模型(ONNX/CoreML/TFLite格式)、3D人体资产、动作库、环境理解决策
- 你提供:UI/UX、渲染引擎集成、相机/麦克风调用、商城分享等业务功能
- 不需要你碰任何模型训练/量化/安全壳(已封装)

■ 二、技术选型(建议,可讨论)
- 跨平台框架:Flutter 或 React Native(一套代码覆盖iOS+安卓+平板)
- 3D渲染:iOS优先SceneKit/Metal;跨平台用 Unity as a Library 或 filament(Google开源);T2低端机走2.5D预渲染序列
- AI推理:直接加载模型侧导出的ONNX/CoreML/TFLite;设备分档检测代码由模型侧提供

■ 三、数据合同(三者融合的接口,文件级低耦合)
App只和三类文件打交道:
1. avatar资产:avatar.obj(13718顶点人体网格)+anim.npy(动作序列,如walk12/turn8/wave5)+meta.json(年龄/性别/身高/体重/民族)
2. 环境包 scene_package/:scene.obj(3D场景)+textures/(2K手机/4K PC贴图)+lighting.json(晨/午/夜光照预设)+navmesh.obj(可行走区域,人只能在此区域走)+spawn_points.json(出生点)+ambient.ogg(环境音可选)
3. 导演指令 intent.json:模型侧输出的决策,形如:
   {"scene_id":"wedding_hall","outfit_id":"formal_03","action_id":"bow","light_preset":"warm_gold","params":{...}}
   App收到后:加载对应环境→给avatar换装→播动作→打光。

■ 四、核心功能模块×接口对照
| App功能 | 你做的 | 模型侧给的 |
|---|---|---|
| 拍照/相册/三视图引导拍摄(转体提示UI) | 相机API+引导层 | pose质检模型(判断照片可用性) |
| 虚拟自己创建 | 表单(年龄/身高/体重/性别/国家/民族,支持只填部分) | gen_virtual_self(数据不全自动补全,返回inferred标注哪些是推算) |
| 数据+脸部照片 | 脸照上传UI | apply_face(脸照影响脸型/肤色) |
| 3D展示间 | 渲染引擎+相机控制(旋转/缩放/打光) | obj+动作库+PC蒙皮(已实测:迈步腿区3190顶点随动) |
| 换装试衣 | 衣橱UI+试穿结果展示 | try_model.onnx(输入人照+衣照→试穿图);同一服装纹理可UV贴到3D衣服网格(2D/3D两用) |
| 穿搭推荐流 | 信息流/卡片UI | style四头.onnx(一图→品类/颜色/风格/场景,63ms) |
| 拍照测量 | AR标定线UI(引导用户站姿) | measure.onnx(±0.7cm→真值校准后±0.4cm) |
| 化妆 | 素颜拍照+强度滑杆 | glow.onnx(可调上妆强度) |
| 宠物 | 宠物拍照UI | pet_model.onnx+本地品种识别(120类,96.2%) |
| 语言/环境指令 | 麦克风+ASR(系统自带即可) | 意图中枢(规则版立即可用:12动作+10场景;后续升级微型LLM) |

■ 五、人-衣-世界的空间规则
1. 人衣1:1:衣服是绑定同一骨骼的外层网格(非贴图)。尺寸1:1(测量数据驱动版型)、姿态1:1(同骨骼同步动)、层级1:1(衣物永远在人体表面外约0.8cm,碰撞约束防穿模)
2. 虚拟自己行走:只在navmesh可行走域内移动,不掉出地板
3. 设备分档渲染:
   - PC:4K贴图+体积光+反射
   - T1(iPhone13+/骁龙8系):实时3D渲染,2K贴图,60fps,36帧动画
   - T2(2020中端安卓):2.5D模式——全景照片做球面背景(人在前景、环境在后景),预渲染多角度序列15-24帧,成本降90%
   - 平板:同T1,贴图升1024-2K

■ 六、安全与合规(零容错,App侧配合)
- 模型包自带反调试:破解只输出乱码(App侧不要绕过/不要二次打包模型)
- 禁忌拦截(TabooNet):涉及宗教/民族等敏感输入会被模型侧拦截,App侧如实展示拦截结果,不做旁路
- 隐私:全部推理离线本地,不联网上传图像(这是产品卖点,App权限申请要最小化)
- 训练数据对外只说"自建数据集",不提任何品牌/来源

■ 七、开发顺序(对齐模型侧进度)
第1步(现在):壳+导航+拍照+虚拟自己表单——模型侧提供样例数据包,可先用假数据跑通全部UI
第2步(+2周):接入抠图/测量/穿搭三模型(已毕业稳定)
第3步(+1月):3D展示间(环境包规范+人体资产+动作库已就绪,你接渲染)
第4步(后续):换装/化妆/宠物逐模块上线

■ 八、体积与性能预算(红线)
- 模型侧总预算≤500MB(其中环境包10个≈100MB)
- 单帧渲染:T1手机60fps(13718顶点人体+2K场景为轻载)
- 模型推理63ms(CPU)——不能在UI主线程跑,放后台线程+结果回调

■ 九、交付物请求(给App开发者)
1. 按第四节的模块清单出开发排期
2. 确认渲染引擎选型(SceneKit/Unity嵌入/filament)
3. 首版里程碑:拍照+表单+假数据3D预览
