# ACmodus 需求总表(一次定稿,后期不再反复提示)

> v1.0 2026-09-17 | 本表=用户全部明确需求的唯一权威来源。此后Agent按表自主执行,不再向用户重复确认表内任何内容。

## 一、项目唯一目的
训练端侧模型,装进手机,离线运行。训练目标:足够轻量+性能10倍好(体积≤1GB红线/600MB目标、内存≤3GB、推理比大模型快10倍)。一切采集调研开发都为此服务。

## 三、目标机型(硬约束)
iPhone 13(A15/4GB)+2020年起的安卓(骁龙865级)必须可用(两大阵营全覆盖)。
能力:真3D穿搭(动态)/换脸/拍照测量人体数据。部署:CoreML(ANE)+NNAPI/Hexagon,INT8。

## 四、体积总红线(v2.1)
- App安装总占用≤1GB红线/≤600MB目标;运行内存≤3GB;用户数据+缓存≤1.5GB自动封顶
- 六模块预算(MB):VTON 350/换脸80/3D基底80/化妆30/测量15/穿搭15/抠图10/预留20
- 衣服3D资产按需下载不打包;生成图LRU封顶500MB;详见 端侧体积红线v2.1-六模块版.md

## 五、工作方式(铁律)
1. 全自主执行不问用户确认(你自己干活训练不要我点确认/自己想办法)
2. 所有要求当场归档,绝不反复问已回答的问题
3. Agent维护记忆文档,新要求/进展立即更新
4. 遇阻先自查三轮,无解才上报(问题+已试方案+需要的决策)
5. 每完成一项:更新记忆文档+推GitHub技能库(kailin58/acmodus-agent-skills)
6. 语音消息先转写再执行(faster-whisper已装)

## 六、项目铁律(不可违反)
- 公平性零容忍:肤色/体型/年龄/性别/残障/容貌焦虑;歧视词表零命中才可发布
- 训练数据分布:Fitzpatrick I-VI全谱系/S-XXL+大码/18-60+/含残障样本
- 隐私:照片零上传/纯端侧离线/偏好画像存本地
- 许可:只用Apache 2.0/MIT级可商用(排除SMPL/NC系)
- 架构:3D空间+虚拟形象+端侧模型一套不可拆;Demo不含换装=不算版本;降级只降渲染不砍换装
- 温度规则:24.5°C分界+七档+分时段(季节场景搭配规则.json)
- 用户偏好>算法:负反馈永久过滤
