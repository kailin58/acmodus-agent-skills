# 端侧安全壳规格 v1.0(基础建设P1)

> 四层防护,你定的铁律:只收图/无文字通道/破解乱码/输出白名单

## 第1层 输入白名单
- 唯一入口:图像解码器(jpeg/png/webp,≤20MB,≤8000px)
- 解码失败/非图像字节流 → 返回乱码帧(固定噪声种子,不泄露错误信息)
- 无任何文本输入通道(API层物理不存在text参数)

## 第2层 完整性校验门(启动时+每24h)
- 包内自校验:模型分片SHA256清单+签名 Ed25519
- 证书钉扎:模型仓CDN证书指纹硬编码
- 校验失败 → 权重位翻转注入(每第17位XOR)+解码噪声种子污染
  → 输出恒为乱码,不可逆,必须重装

## 第3层 输出白名单
- 推理结果必须匹配六模块schema(图/mesh/数值/JSON)
- schema外字段一律丢弃
- 无文本生成头(模型物理上不含LM head)

## 第4层 反调试
- 检测:ptrace/Frida hook/越狱标志/模拟器特征
- 触发 → 同第2层乱码注入
- 所有触发事件本地记录(零上传,升级时带哈希摘要)

## 物理裁剪
- 导出时裁掉一切非任务头(分类头只留7模块标签表)
- 模型文件加密存储(AES-256,密钥派生自签名证书)
