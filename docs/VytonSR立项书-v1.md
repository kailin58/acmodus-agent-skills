# VytonSR 立项书 v1
> 2026-10-14 用户令立项 · 三域通用呈现增强技术(体积不变画质+)

## 一、定义
**VytonSR** = 感知引导的编解码协同呈现增强技术:
- 编码侧"存得聪明"(显著性比特分配+抖动预处理)
- 算法侧"显示时补回"(高频重建头+时域借用)
- 体积几乎不变(资产+0,共享重建头0.5MB),主观画质8.7→9.4+

## 二、三域通用(一套技术)
| 域 | 落地 | 收益 |
|---|---|---|
| 图片 | 直接过重建头 | 压缩图视觉无损化 |
| 3D | 贴图加载时过一遍(0运行时开销) | ETC1S 329KB体验≈原图 |
| 视频 | 逐帧重建+时域借用 | 三域中收益最大 |

核心原理:三域失真同源(高频丢失),重建头学"低频→高频"=域无关。

## 三、技术构成(R1-R4)
- R1 抖动预处理:防暗部banding,0成本(本周)
- R2 高频重建头:轻量U-Net 0.5MB,自高频注入技术三度应用(v9b手部9分/v9.2宠物9.0验证)(2周)
- R3 显著性比特分配:品类头改造引导分块质量(1个月)
- R4 时域借用:前帧高频复用(DLSS原理)(随视频模块)
