## 二、项目背景速览(来自仓库文档,已核实)

- **一句话**:用Qwen自训换装能力,蒸馏≤500MB端侧模型装进手机App,纯端侧离线,隐私零上传
- **进度**:M1推理验证✅(Qwen-Image-Edit-2509 API换色7.5/10) → M2 LoRA微调⏸️待跑(10对样本500步,魔搭A10) → M3全量13k对 → M4蒸馏415M(Mobile-VTON方法:TGT+FGA) → M5端侧部署(ONNX/INT8,首版≤80s/张) → M6风格知识库(并行)
- **规格铁律**:总包≤500MB、内存≤3GB、能力分级L1-L4
- **公平性零容忍**:肤色/体型/年龄/性别/残障/容貌焦虑,歧视词表扫描零命中才可发布;训练数据 Fitzpatrick I-VI 全谱系+S-XXL+大码+18-60+含残障
- **风格基因**(来自知识库):静奢/法式/复古/通勤;莫兰迪-裸-驼-灰;羊毛/真丝/醋酸;场景=都市通勤/日常/秋冬叠穿/春夏轻装
- **温度规则**:24.5°C分界线(高于=短袖,低于=长袖/加外套),七档分层+早中晚分时
- **架构**:五层(3D空间/Avatar换装/EdgeAI/FashionData/Cloud);3D衣帽间+虚拟形象+换装是一套系统不可拆;任何版本Demo不含换装=不算达成版本目标
