【ACmodus 端侧AI形象系统 — 协作需求书 v2.0】
(给:App开发者 × 环境开发者)

═══════════════════════════════════
一、目标(我们要做成什么)
═══════════════════════════════════
做一款手机离线AI形象App:用户拍几张照/填基础数据,生成自己的3D虚拟分身;分身能试穿衣服、上妆、听懂"走两步/跳个舞"等指令做动作、站在婚礼/健身房等虚拟环境里展示穿搭;还能给宠物虚拟穿毛衣、拍照量体(肩宽±0.4cm)。
硬指标:全部AI离线本地跑;模型总体积≤500MB;内存≤3GB;iPhone13+/2020安卓可流畅;推理63ms级;破解只出乱码(安全壳零容错)。

═══════════════════════════════════
二、背景与问题(为什么难,需要协作)
═══════════════════════════════════
背景:模型侧已训练完7个AI模块(总体93%):①穿搭识别(四头一次出品类/颜色/风格/场景)②换装试穿(9.4/10)③虚拟自己3D(9阶段年龄/4种输入/23帧动作)④化妆⑤抠图(IoU 0.9895)⑥拍照测量(±0.7cm)⑦宠物(9.17配方)。
问题:AI模型再好,装不进手机、跑不流畅、界面难用=零。三个角色必须咬合:
- 模型侧(已完成):轻量模型+标准导出
- 你(App):把模型能力变成顺滑体验
- 你(环境):3D环境资产+渲染落地
任何一环掉链子,用户体验就断。所以定了下面的协作契约。

═══════════════════════════════════
三、怎么协作解决(契约与流程)
═══════════════════════════════════
【数据合同:三方只通过文件说话】
1. avatar资产包(模型侧→App):
   avatar.obj(13718顶点人体,含蒙皮)+
   anim/*.npy(动作序列)+
   meta.json(用户参数+推算标注)
2. 环境包(环境侧→App):
   scene.obj+textures/+lighting.json+
   navmesh.obj(可行走域)+spawn.json
3. 导演指令(模型侧→App,运行时):
   intent.json:
   {scene_id, outfit_id, action_id, light_preset, params}
【协作流程】
模型侧导出模型+manifest → App侧按manifest加载
→环境侧按环境包规范出资产 → App组装渲染
→三方各改各的,互不阻塞(文件级低耦合)
【联调节奏】
每两周一次三端联调:模型侧出样例包→App跑通
→列问题清单→各自修→复验。问题进共享表格,
标[模型|App|环境]责任方。

═══════════════════════════════════
四、模型运行条件(重点:通用格式)
═══════════════════════════════════
【统一清单文件:manifest.json(每个模型一份,与模型文件同目录)】
{
  "model_id": "style_v16",
  "version": "1.0.0",
  "task": "multi_label_classify",
  "file": "style_v16.onnx",
  "format": "onnx",              // onnx|coreml|tflite 通用三选一
  "size_mb": 40,
  "input":  [{"name":"image","type":"float32","shape":[1,3,160,160],"norm":[0,1],"layout":"CHW","color":"RGB"}],
  "output": [{"name":"cat","shape":[1,9]},{"name":"col","shape":[1,12]},{"name":"sty","shape":[1,8]},{"name":"sce","shape":[1,6]}],
  "postprocess": "sigmoid→阈值0.5→标签映射见labels.json",
  "runtime": {"cpu_ms":63,"threads":4,"quant":"int8可选","min_ram_mb":60},
  "device_tier": ["T1","T2","PC"],
  "labels": "labels.json"
}
→App只需写一个"读manifest→加载→喂输入→收输出"的通用加载器,七个模型一套代码全兼容;新模型上线=放新文件夹+新manifest,App零改动。

【格式选择(按平台自动)】
iOS:.coreml(CoreML原生,ANE加速)
安卓:.tflite(NNAPI/GPU delegate)
跨平台/PC:.onnx(ONNX Runtime)
同一模型三个格式,文件名同id不同扩展名。

【运行环境最低要求】
T1(iPhone13+/骁龙8系及以上):
  全模块实时;3D渲染60fps;36帧动画
T2(2020中端安卓):
  全模型可跑(63ms CPU);渲染降2.5D
  (球面全景背景+预渲染序列15-24帧)
PC(任何近5年):
  全功能,渲染升4K
内存红线:峰值≤3GB(模型加载~500MB+
渲染~800MB+系统余量)
线程纪律:推理放后台线程,结果回调UI;
禁止主线程跑模型(卡界面)
